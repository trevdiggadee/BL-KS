# Neon Blocks

A mobile-first falling-block puzzle game built with HTML/CSS/JavaScript.

## Deploy

Upload this folder to GitHub and connect the repository to Cloudflare Pages/Workers static assets.

## Data

Player statistics and settings are stored locally on the device. No account or backend is required.

## iPhone

Open the deployed site in Safari and use **Share → Add to Home Screen**.

## Important

This project uses the original name **Neon Blocks** rather than the trademarked Tetris name/branding.


## File layout
All project files are intentionally kept in one directory for easy GitHub uploading/editing on iPhone.
